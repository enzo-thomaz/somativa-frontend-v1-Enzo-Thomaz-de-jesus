# 💻 Cinema POP

Somos uma emrpessa de cinema onde procuramos o alto conforto e experiencia unica! entre no nosso site e venha conhecer, tanto filmes novos quantos antigos. Todos os publicios são bem vindos![Tema].

## 🛠️ Tecnologias Utilizadas
* utilizamos CSS  para a estilização do site para o agrado visual
* HTML para fazer o site e a separação das atividades
* e o script para a interatividade

## 📁 Estrutura do Projeto
O projeto foi organizado seguindos boas praticas de mercado:

.A primeira parte do projeto foi analisar o css, para dexar visualmente agradvel para todos, logo depois foi a escrita do html, o esqueleto do site, tudo oq é possivel ver em nossa loja, e por ultimo o script, para deixar nosso site mais caracterizado e arrumado.



## 🚀 Funcionalidades Implementadas
* **Interatividade Visual:** novas cores agradveis para todos os publicos.
* **Saudação Dinâmica:**emprestar filme ate os dias atuais e muitas promoçôes
* **Cálculo em Tempo Real:** Formulário que processa e exibe resultados assim que o usuário digita.
* **Injeção de Conteúdo:**  avaliação e opinião dos clientes da loja e de fora
